# PARCC Algebra I course fixtures

Real NJDOE workbook slices for 2015-2018. Each retains the original three
preamble/header rows, the first All Students row at school, district and state
levels, one suppressed row, and the final two source rows. Values
and labels are copied without alteration using openpyxl (data_only=True).
provenance.json records source URLs, source and fixture SHA-256 digests, and
original Excel row numbers (one-based). These small slices are for tests only.
