# Retrieve raw NJGPA data with source provenance

Retrieve raw NJGPA data with source provenance

## Usage

``` r
get_raw_njgpa_result(end_year, subj, request_fn = .default_source_request)
```

## Arguments

- end_year:

  School-year end year.

- subj:

  Subject.

- request_fn:

  Injectable transport request function.

## Value

An \`njsd_source_result\`.
