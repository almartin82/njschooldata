# Resolve a registered NJ DOE source URL

Resolve a registered NJ DOE source URL

## Usage

``` r
resolve_source_url(data_type, end_year = NULL, ...)
```

## Arguments

- data_type:

  Registered family name or alias.

- end_year:

  School-year end year, where applicable.

- ...:

  Resolver-specific fields such as \`grade\`, \`subject\`, or \`level\`.

## Value

One or more candidate source URLs.
