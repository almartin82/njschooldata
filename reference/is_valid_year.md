# Check whether a year is supported

Check whether a year is supported

## Usage

``` r
is_valid_year(end_year, data_type, capability = c("tidy", "raw"))
```

## Arguments

- end_year:

  School-year end year.

- data_type:

  Registered family name or alias.

- capability:

  Either \`"tidy"\` or \`"raw"\`.

## Value

A single logical value.
