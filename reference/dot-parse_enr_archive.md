# Parse a validated zipped fall enrollment artifact

Parse a validated zipped fall enrollment artifact

## Usage

``` r
.parse_enr_archive(tname, end_year)
```

## Arguments

- tname:

  Path to a validated NJ DOE enrollment ZIP.

- end_year:

  A school year. Year is the end of the academic year - eg 2006-07
  school year is year '2007'.

## Value

Data frame with raw enrollment data
