# Get raw OPRA IEP counts by district and grade

Get raw OPRA IEP counts by district and grade

## Usage

``` r
get_raw_sped_by_grade(end_year)
```

## Arguments

- end_year:

  ending school year, 2022 through 2026.

## Value

one row per district in the year, every cell as character, exactly as
NJDOE released it.
